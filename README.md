# xulo-website

This is a Tanstack Start application generated with
[Create Fumadocs](https://github.com/fuma-nama/fumadocs).

Run development server:

```bash
npm run dev
# or
pnpm dev
# or
yarn dev
```

## Language specification (git submodule)

The normative spec lives in [xulo-lang/spec](https://github.com/xulo-lang/spec)
and is vendored as a git submodule at `content/spec`. The `/docs/spec` pages
are generated from it into `content/docs/en/spec` (the zh pages fall back to
the English content automatically).

Clone with submodules:

```bash
git clone --recurse-submodules https://github.com/xulo-lang/website.git
# or, for an existing clone:
git submodule update --init content/spec
```

`predev` / `prebuild` regenerate the pages automatically; to sync manually:

```bash
npm run spec:sync
```

To bump the spec to a newer revision:

```bash
git submodule update --remote content/spec
npm run spec:sync
git add content/spec content/docs/en/spec
```

Never edit `content/docs/en/spec/**` directly — it is generated by
`scripts/sync-spec.mjs` (chapter order comes from the Document Map table in
the spec README).
