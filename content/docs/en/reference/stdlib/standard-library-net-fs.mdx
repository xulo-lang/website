## Overview

The XULO standard library (`std`) provides high-order data structures, I/O, networking, async runtime, and other core capabilities. Language built-in primitives (such as `spawn`, `lock`, `shared`, `list`, `map`, `set`, `JSON`) are not included in this directory; `std::*` modules are only imported explicitly when needed.

## Design Principles

1. **Zero Contamination & Cross-Platform**: `std::*` core library guarantees consistent behavior across all targets (including Native OS, embedded, and WebAssembly) without platform-specific rendering logic
2. **Separation of Primitives and std**: `spawn`, `lock`, `shared`, and `list` / `map` / `set` / `JSON` are language built-in primitives, not included in this directory

## Module Directory

```
std/
├── collections.xulo      // High-order data structures
│   ├── HashMap<K, V>     // Custom Hasher & memory layout
│   ├── BTreeMap<K, V>    // Ordered key-value mapping
│   ├── HashSet<T>        // Unique value collection
│   └── Deque<T>          // Double-ended queue / concurrent queue
│
├── fs.xulo               // File system & I/O (async/sync)
│   ├── File              // File handle, read / write API
│   └── Path              // Path concatenation, extraction & normalization
│
├── net.xulo              // Network communication basics
│   ├── TcpStream         // TCP stream
│   ├── TcpListener       // TCP listener
│   ├── UdpSocket         // UDP socket
│   ├── http.fetch()      // HTTP client request
│   └── HttpListener      // HTTP server listener
│
├── async.xulo            // Async & coroutine runtime control
│   ├── sleep(ms)         // Async sleep
│   ├── interval(ms)      // Timer
│   ├── Task              // Task handle control, cancel, join
│   └── channel           // Async MPSC / Broadcast channels
│
├── thread.xulo           // Low-level OS physical thread control
│   ├── Builder           // Thread config (stack size, thread name, etc.)
│   └── current           // Thread ID & context management
│
├── sync.xulo             // Low-level & high-level concurrency primitives
│   ├── AtomicBool        // Atomic boolean
│   ├── AtomicI64         // Atomic 64-bit integer
│   ├── Semaphore         // Semaphore
│   └── Barrier           // Barrier & condition variables
│
├── process.xulo          // System-level process & environment interaction
│   ├── Command           // External system command execution & sandbox dispatch
│   └── env.args()        // Environment variable reading & command-line argument parsing
│
├── math.xulo             // Math computation & random numbers
│   ├── PI, E             // Math constants
│   ├── sqrt, log         // Trigonometric functions, square root, logarithm, etc.
│   └── random            // High-performance pseudo-random number generator
│
└── time.xulo             // High-precision time & timezone
    ├── Instant           // High-precision monotonic timestamp
    ├── Duration          // Duration
    └── DateTime          // Formatting & parsing
```

## Usage Examples

```js
// Import standard library modules
import { HashMap, BTreeMap, HashSet, Deque } from "std/collections"
import { File, Path } from "std/fs"
import { http } from "std/net"
import { sleep, interval } from "std/async"
import { AtomicI64 } from "std/sync"

// Use HashMap (high-order data structure, distinct from built-in map primitive)
let users = HashMap<string, User>.new()
users.insert("alice", User { name: "Alice" })

// JSON serialization (built-in primitive, no import needed)
let data = { name: "Alice", age: 30 }
let json_str = JSON.stringify(data)
let parsed = JSON.parse<User>(json_str)

// File I/O
let file = File.open("data.txt", mode: Write)
file.write("Hello, XULO!")
file.close()

// HTTP request
let response = http.fetch("https://api.example.com/data")
let body = response.body()

// Async timer
spawn async {
    sleep(1000)
    print("1 second later")
}
```

## Built-in Primitives vs Standard Library

| Category | Built-in Primitives | Standard Library Extensions |
| --- | --- | --- |
| **Collections** | `list<T>`, `map<K, V>`, `set<T>` | `HashMap`, `BTreeMap`, `HashSet`, `Deque` |
| **Concurrency** | `spawn`, `shared`, `lock` | `async/task`, `sync/atomic`, `sync/semaphore` |
| **I/O** | - | `fs/file`, `fs/path`, `net/tcp`, `net/http` |
| **Data** | `JSON.stringify`, `JSON.parse` | - |
| **System** | - | `process/command`, `process/env` |
| **Math** | - | `math/constants`, `math/numeric`, `math/random` |
| **Time** | - | `time/instant`, `time/duration`, `time/date_time` |

Built-in primitives are directly supported by the compiler without import; standard library modules require explicit `import` to use.
