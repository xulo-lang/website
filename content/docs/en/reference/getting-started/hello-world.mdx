## Terminal Program

Every XULO program has a `fn main()` entry point. Create a new file with the following:

```js
fn main() {
  println("Hello World")
}
```

Running it outputs:

```
Hello World
```

`println` prints to the terminal. This is a complete XULO program — no boilerplate, no imports, just one function. A plain `fn main()` runs headlessly: the body executes and nothing is laid out or painted.

## Functions with Parameters

Functions are declared with the `fn` keyword, with typed parameters:

```js
fn greet(name: String): String {
  `Hello, ${name}`
}

fn main() {
  println(greet("XULO"))
}
```

Output:

```
Hello, XULO
```

The last expression in a function body is the implicit return value — no `return` needed. Types are capitalized (`String`, `Int`, `Boolean`), and a template literal in backticks interpolates while `"..."` and `'...'` never do.

## Structs & Methods

Define data structures with `struct`, add methods with `impl`:

```js
struct Rectangle {
  w: Int,
  h: Int
}

impl Rectangle {
  fn area(self): Int {
    self.w * self.h
  }

  fn is_square(self): Boolean {
    self.w == self.h
  }
}

fn main() {
  let r = Rectangle(w: 3, h: 4)
  println(str(r.area()))       // 12
  println(str(r.is_square()))  // false
}
```

The receiver is an explicit `self` parameter; a method that assigns to itself or a field declares `mut self`. `str(x)` converts explicitly, because `+` never mixes strings and numbers.

## Conditionals & Loops

```js
fn main() {
  // if expression
  let x = 10
  let label = if x > 5 { "large" } else { "small" }
  println(label)

  // for loop
  for i in 1..<5 {
    println(str(i))
  }
}
```

`if` used as an expression requires both branches to have a common type. `1..<5` is a half-open range (`1...5` is closed), and `for` also iterates `List`, `Map` (its keys), and `Set`.

## UI Programs

A function whose declared return type is `View` **is** a component — the return type marks it, not the name:

```js
fn Greeting(): View {
  VStack(spacing: 16) {
    Text("Hello, XULO!")
    Button("Click Me", variant: "primary")
  }
}

fn main(): View {
  Screen {
    Center {
      Greeting()
    }
  }
}
```

`fn main(): View` tells the host this is a renderable program: it invokes `main`, lays out and paints the returned tree, and invokes it again for every later pass. `VStack` stacks children vertically, `Center` centers its content, and `Screen` is the root container — all recommended library components, not reserved words.
