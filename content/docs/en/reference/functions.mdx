## Function Definition

```js
// No return value
fn log(message: string) {
  print(message)
}

// With return value (implicit return, Rust style)
fn add(a: number, b: number): number {
  a + b
}

// Explicit return
fn subtract(a: number, b: number): number {
  return a - b
}
```

**Rules:**

- Use the `fn` keyword (Rust style)
- Parameter types use `:` (TypeScript/Swift style)
- Return types use `:` (TypeScript/Swift style)
- Last expression without semicolon = implicit return (Rust style); **when a return type is declared, the trailing expression must match it**
- `return` for explicit return is also supported
- Omit the return type when there is no return value

## Parameters

### Optional Parameters (`?`)

```js
fn greet(name: string?): string {
  if name != null {
    "Hello, " + name
  } else {
    "Hello, stranger"
  }
}

greet()      // OK, name = null
greet("A")   // OK
```

### Default Parameter Values (`=`)

```js
fn greet(name: string = "stranger"): string {
  "Hello, " + name
}
```

### Named Parameters

```js
fn Button(label: string, variant: string = "primary"): View

Button(variant: "outline", label: "Submit")  // Named args, can be out of order
```

- Call-site named arguments `greet(name: "X")` are supported; once named arguments are used, all arguments must be named, and they can be out of order
- String literal union types (`type Status = "active" | "inactive"`) accept the corresponding literals at call sites

## Generic Functions

```js
fn first<T>(list: list<T>): T {
  list[0]
}

// Type argument inferred at call site: first([1, 2, 3]) binds T to number
let n: number = first([1, 2, 3])
let s: string = first(["a"])      // OK, T = string
let bad: string = first([1, 2])   // Error, T inferred as number
```

> The current implementation supports **call-site inference** for generic type arguments. **Explicit** type arguments (`first<number>(...)`) are not yet supported.

## Anonymous Functions / Closures

`fn` can also appear in expression position as a value (closures capture the outer scope, equivalent to JS closures):

```js
fn apply(f: fn(number): number, x: number): number {
  f(x)
}

fn makeAdder(n: number): fn(number): number {
  fn(v: number): number { v + n }   // Captures n
}

fn main() {
  let double = fn(x: number): number {
    x * 2
  }

  let add5 = makeAdder(5)
  print(apply(double, 3))   // 6
  print(add5(10))           // 15

  // Async closure: async fn()
  let work = async fn() { 42 }
  let v = await work()      // 42
}
```

**Rules:**

- Anonymous function type is `fn(param types): return type` (`Type::FnSig`), assignable to parameters/variables with that type
- Automatically accesses outer local variables through capture; mutable captures can modify outer `let` bindings directly
- Function values are called with positional arguments only; the count must match exactly; named arguments are not supported
- Function values can be called from any expression: `xs[0](10)`, `getFn()(x)`, `(f)(5)`
- `fn(...)` in statement position (e.g., at the end of a block for implicit return) is parsed as an anonymous function expression
- Async closures are written as `async fn()`, return a Promise when called, and can be `await`ed
