## Operator Precedence (High → Low)

```text
Postfix            x.y  x[i]  f(x)  x?.y
Unary              !  -  await
Multiply/Divide    *  /
Add/Subtract       +  -
Comparison/Equal   <  >  <=  >=  ==  !=  ..<
Nullish            ??
Logical And        and
Logical Or         or
Ternary            ?:
Assignment         =
```

> Note: The implementation merges equality (`==`/`!=`) and comparison (`<`/`>`/`<=`/`>=`) into the same precedence level, left-associative.

## Logical and Ternary

```js
let ok = a > 1 and b < 2       // `and` / `or` (not `&&` `||`)
let n = a > 1 ? "big" : "small" // Ternary
print(!flag)                    // Logical not
```

## String Concatenation

```js
let who = "Xulo"
print("Hello, " + who + "!")        // `+` concatenates strings
print("count=" + str(count))        // `str(x)` converts any value to string
```

**Rules:**

- `number + number` → `number`
- `string + string` (including string literal types) → `string`
- `list<T> + list<U>` → concatenated `list`
- **Mixed types are prohibited**: `"hi" + 1`, `"hi" + true`, etc. cause errors; use `str(x)` to convert before concatenating

## Member Access / Subscript / Optional Chaining / Nullish Coalescing

```js
user.name           // Member access
xs[0]               // Subscript
user?.name          // Optional member access (null if object is null)
let name = user?.name ?? "anonymous"   // Nullish coalescing
```

## List Spread

```js
let head = [1, 2]
let tail = [3, 4]
let all = [...head, ...tail]   // Spread and merge
let withExtra = [...all, 9]
```

`...` can only appear inside list/object literals; the operand must be `list<T>` or an object.

## Object Spread

```js
let base = { a: 1 }
let copy = { ...base, b: 2 }   // Spread and merge
```

## `match` as Expression

`match` is an expression (see [Control Flow](/en/docs/reference/basics/control-flow-and-matching/)):

```js
let label = match status {
  0 => "zero"
  1 => "one"
  _ => "other"
}
```

## Function Value Calls

Function values can be called from any expression:

```js
xs[0](10)        // Call a function in a list
getFn()(x)       // Call a returned function
(f)(5)           // Call a parenthesized function value
```
