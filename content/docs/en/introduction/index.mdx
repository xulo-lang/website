XULO is a cross-platform UI layout for optimal human/AI reading. A document is a tree of components, each with typed attributes and optional child elements.

Uppercase names are components; lower camelCase names are attributes and named values. There are no closing tags and no angle brackets — structure comes from the opening `{` block.
