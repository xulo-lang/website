XULO 是一种跨平台 UI 布局语言，面向人/AI 最优阅读。文档是由组件组成的树形结构，每个组件具有类型化的属性和可选的子元素。

大写名称是组件；小驼峰名称是属性和命名值。没有闭合标签，也没有尖括号——结构来自 `{` 块。
