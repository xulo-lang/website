## 概述

XULO 标准库（`std`）提供高阶数据结构、I/O、网络、异步运行时等核心能力。语言内建原语（如 `spawn`、`lock`、`shared`、`list`、`map`、`set`、`JSON`）不包含在此目录中；`std::*` 模块仅在显式 `import` 时引入对应类型与函数。

## 设计原则

1. **零污染与跨平台**：`std::*` 核心库保证在所有 Target（包括 Native OS、嵌入式及 WebAssembly）上行为一致且不包含特定平台的渲染逻辑
2. **原语与 std 分离**：`spawn`、`lock`、`shared` 以及 `list` / `map` / `set` / `JSON` 均属语言内建原语，不包含在此目录中

## 使用示例

```js
// 导入标准库模块
import { HashMap, BTreeMap, HashSet, Deque } from "std/collections"
import { File, Path } from "std/fs"
import { http } from "std/net"
import { sleep, interval } from "std/async"
import { AtomicI64 } from "std/sync"

// 使用 HashMap（高阶数据结构，区别于内置 map 原语）
let users = HashMap<string, User>.new()
users.insert("alice", User { name: "Alice" })

// JSON 序列化（内置原语，无需导入）
let data = { name: "Alice", age: 30 }
let json_str = JSON.stringify(data)
let parsed = JSON.parse<User>(json_str)

// 文件 I/O
let file = File.open("data.txt", mode: Write)
file.write("Hello, XULO!")
file.close()

// HTTP 请求
let response = http.fetch("https://api.example.com/data")
let body = response.body()

// 异步定时器
spawn async {
    sleep(1000)
    print("1 second later")
}
```

## 内置原语 vs 标准库

| 类别 | 内置原语 | 标准库扩展 |
| --- | --- | --- |
| **集合** | `list<T>`, `map<K, V>`, `set<T>` | `HashMap`, `BTreeMap`, `HashSet`, `Deque` |
| **并发** | `spawn`, `shared`, `lock` | `async/task`, `sync/atomic`, `sync/semaphore` |
| **I/O** | - | `fs/file`, `fs/path`, `net/tcp`, `net/http` |
| **数据** | `JSON.stringify`, `JSON.parse` | - |
| **系统** | - | `process/command`, `process/env` |
| **数学** | - | `math/constants`, `math/numeric`, `math/random` |
| **时间** | - | `time/instant`, `time/duration`, `time/date_time` |

内置原语由编译器直接支持，无需导入；标准库模块需要显式 `import` 才能使用。
