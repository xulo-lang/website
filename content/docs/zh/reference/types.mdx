## 基础类型

```js
string         // 字符串
number         // 数字（整数和浮点统一）
boolean        // 布尔值
list<T>        // 列表（泛型）
object         // 对象（结构体）
null           // 空值
T?             // 可选类型（Swift 风格，等价于 T | null）
T | U          // 联合类型（TypeScript 风格）
T & U          // 交叉类型（TypeScript 风格）
```

`number` 统一表示整数与浮点。`print(...)` 和 `list<T>` 是内建能力。`View` 是内建**标记类型**：编译器用它识别「返回该类型的函数即 UI 组件」，本身无运行时实现，具体组件由标准库 `@xulo/ui` 提供。

## 类型别名（统一使用 `type`，无 `interface`）

```js
// 对象类型
type User = {
  name: string
  age: number
  email: string?
}

// 联合类型
type Status = "active" | "inactive" | "pending"

// 函数类型
type Handler = fn(request: Request): Response

// 交叉类型
type UserWithRole = User & {
  role: string
}

// 泛型
type Result<T> = {
  data: T?
  error: string?
}
```

## 结构体（struct）

`struct` 定义一个具名记录类型，包含显式字段，与 Rust 类似。每个字段有名称和类型。

```js
struct User {
  name: string
  age: number
  email: string?
}
```

### 创建实例

```js
let user = User(name: "Alice", age: 30, email: "alice@example.com")
let anon = User(name: "Bob", age: 25, email: null)
```

可选类型（`T?`）的字段可以省略，默认为 `null`。

### 字段访问

```js
print(user.name)       // "Alice"
print(user.age)        // 30
user.age = 31          // 通过 `let` 绑定可修改字段
```

### 实现方法

使用 `impl` 为结构体附加方法。`self` 是接收者：

```js
struct Rectangle {
  w: number
  h: number
}

impl Rectangle {
  fn area(self): number {
    self.w * self.h
  }

  fn perimeter(self): number {
    2 * (self.w + self.h)
  }

  fn is_square(self): boolean {
    self.w == self.h
  }
}

fn main() {
  let r = Rectangle(w: 3, h: 4)
  print(str(r.area()))        // 12
  print(str(r.perimeter()))   // 14
  print(str(r.is_square()))   // false
}
```

### 结构体实现特征

结构体可以实现特征以获得多态行为：

```js
trait Area {
  fn area(self): number
}

impl Area for Rectangle {
  fn area(self): number {
    self.w * self.h
  }
}

fn total_area(shapes: list<Area>): number {
  // ...
}
```

### 结构体 vs 类型别名

| 特性 | `struct` | `type`（对象） |
|------|----------|---------------|
| 命名字段 | 是 | 是 |
| `impl` 方法 | 是 | 否 |
| 实现特征 | 是 | 否 |
| 字段可见性控制 | 是（`pub`） | 否 |
| 名义类型 | 是（独立类型） | 结构类型 |

需要方法、特征实现或独立命名类型时使用 `struct`。简单数据结构使用 `type`。

### 规则

- 结构体名称首字母大写
- 字段使用 `name: type` 语法
- 字段在定义模块内默认可变
- 使用 `pub` 导出字段跨模块访问
- 结构体支持泛型：`struct Pair<T> { first: T, second: T }`
- `impl` 块不跨模块移植；在使用该结构体的模块内本地实现

## 枚举类型（enum）

枚举用于定义一组固定的值。

### 简单枚举

```js
enum Theme {
  Light
  Dark
  System
}
```

### 带关联数据的枚举（Swift/Rust 风格）

```js
enum Result<T> {
  Success(T)
  Error(string)
}

enum Action {
  Click
  Submit(data: object)   // 具名关联数据
  Cancel
}

enum Person {
  Nobody
  Named(string, number)  // 多参数 payload
}
```

payload 可以是位置形式 `Success(T)`、具名形式 `Submit(data: object)`，也支持多参数 `Named(string, number)`；构造按位置传参。匹配时每个参数对应一个绑定，用 `_` 丢弃不需要的槽位：

```js
Action::Submit({ message: "hi" })
match a {
  Action::Submit(data) => data
}

let p = Person::Named("Ada", 36)
match p {
  Person::Named(name, _) => name   // 丢弃 age
  Person::Nobody => "anon"
}
```

### 使用

```js
let theme = Theme::Dark

match theme {
  Theme::Light => "☀️"
  Theme::Dark => "🌙"
  Theme::System => "💻"
}

let result = Result::Success(42)
match result {
  Result::Success(value) => print("Got: " + value)
  Result::Error(msg) => print("Error: " + msg)
}
```

### 规则

- 枚举名称首字母大写
- 成员首字母大写
- 关联数据类型放在 `(type)` 中
- 支持泛型（类型参数在类型检查时擦除）

## 特征（trait）

`trait` 声明一组方法签名，作为「能力」契约；`impl Trait for Type` 为某个具名类型提供这些方法的实现。`self`（保留字）作为接收者，标记该方法为「实例方法」。

```js
trait Area {
    fn area(self): number
    fn perimeter(self): number
}

type Rectangle = { w: number, h: number }

impl Area for Rectangle {
    fn area(self): number { self.w * self.h }
    fn perimeter(self): number { 2 * (self.w + self.h) }
}
```

调用通过**显式派发** `Trait::method(接收者, ...)` 进行——编译器把它解析成对 `impl` 方法的静态调用，零运行时开销：

```js
fn main() {
    let r: Rectangle = { w: 3, h: 4 }
    print(str(Area::area(r)))        // 12
    print(str(Area::perimeter(r)))   // 14
}
```

### 泛型约束

类型参数可以用 `T: Trait`（行内）或 `where T: Trait` 约束。多个特征用 `&` 连接：

```js
fn describe<T: Area>(t: T): number {
    Area::area(t)
}
```

### 规则

- 派发接收者必须是**静态具名类型**，否则报「does not implement trait」
- `impl` 方法必须实现 trait 声明的全部方法
- 泛型参数的值在运行时被擦除
- `trait` 是可导出的模块成员（`pub trait`），可被其他模块 `import type` 引入后再本地实现
