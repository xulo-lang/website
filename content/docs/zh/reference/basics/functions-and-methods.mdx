## 函数定义

```js
// 无返回值
fn log(message: string) {
  print(message)
}

// 有返回值（隐式返回）
fn add(a: int, b: int): int {
  a + b
}

// 显式 return
fn subtract(a: int, b: int): int {
  return a - b
}
```

**规则：**

- 用 `fn` 关键字
- 参数类型用 `:`
- 返回值用 `:`
- 最后表达式无分号 = 隐式返回；**声明了返回类型时，尾部表达式须与返回类型匹配**
- 也支持 `return` 显式返回
- 无返回值时省略返回类型

## 参数

### 可选参数（`?`）

```js
fn greet(name: string?): string {
  if name != null {
    "Hello, " + name
  } else {
    "Hello, stranger"
  }
}

greet()      // OK，name = null
greet("A")   // OK
```

### 默认参数值（`=`）

```js
fn greet(name: string = "stranger"): string {
  "Hello, " + name
}
```

### 命名参数

```js
fn Button(label: string, variant: string = "primary"): View

Button(variant: "outline", label: "Submit")  // 命名参数，可乱序
```

- 调用时可用命名参数 `greet(name: "X")`；一旦使用命名参数，所有实参都须命名，且可乱序
- 字符串字面量联合类型（`type Status = "active" | "inactive"`）在实参处接受对应字面量

## 泛型函数

```js
fn first<T>(list: list<T>): T {
  list[0]
}

// 调用处推断类型实参：first([1, 2, 3]) 把 T 绑定为 int
let n: int = first([1, 2, 3])
let s: string = first(["a"])      // OK，T = string
let bad: string = first([1, 2])   // 错误，T 推断为 int
```

> **显式**类型实参（`first<number>(...)`）不受语法规范支持。泛型类型参数始终在调用处推断。

## 闭包

闭包是用 `=>` 编写的匿名函数，自动捕获外层作用域变量（等价 JS 闭包）。`fn` 仅用于具名函数声明。

```js
fn apply(f: fn(int): int, x: int): int {
  f(x)
}

fn makeAdder(n: int): fn(int): int {
  (v: int): int => v + n   // 捕获 n
}

fn main() {
  let double = (x: int): int => x * 2

  let add5 = makeAdder(5)
  print(apply(double, 3))   // 6
  print(add5(10))           // 15

  // 异步闭包
  let work = async () => 42
  let v = await work()      // 42
}
```

### 语法形态规范

#### 单行表达式闭包（类型自动推导）

```js
let add = (a, b) => a + b
let numbers = list.map([1, 2, 3], (x) => x * 2)
```

#### 多行块级闭包（带显式类型与返回类型）

```js
let handler = (event: MouseEvent): boolean => {
    if event.is_valid {
        return true
    }
    false
}
```

#### 闭包类型描述符（用于函数参数类型标注）

`fn(InputType): OutputType`

```js
pub fn filter<T>(items: list<T>, predicate: fn(T): boolean): list<T> {
    // ...
}
```

### EBNF 形式化规则

```text
ClosureExpr      = [ 'async' ] ClosureParams [ ':' Type ] '=>' ( Expression | Block ) ;
ClosureParams    = Identifier
                 | '(' [ ClosureParam ( ',' ClosureParam )* ','? ] ')' ;
ClosureParam     = Identifier [ ':' Type ] ;

ClosureType      = [ 'async' ] 'fn' '(' [ TypeList ] ')' [ ':' Type ] ;
```

### 规则

- `fn` 保留用于具名函数/方法声明；`=>` 用于匿名闭包
- 闭包类型为 `fn(参数类型): 返回类型`，可赋值给带该类型的参数/变量
- 通过捕获自动访问外层局部变量，可变捕获可直接修改外层 `let` 绑定
- 调用函数值时只用位置实参，数量必须精确匹配；具名实参不支持
- 函数值可从任意表达式中调用：`xs[0](10)`、`getFn()(x)`、`(f)(5)`
- 异步闭包写作 `async () => ...`，调用返回 Promise，可用 `await`
