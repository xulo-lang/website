## `async` / `await`

```js
async fn fetchUser(id: string) {
  let response = await fetch("/api/users/" + id)
  let data = await response.json()
  return data
}
```

- `async` 前缀声明异步函数（等价 JS `async function`）
- `await` 只能出现在异步函数内；对非 Promise 值使用 `await` 是语义错误
- `throw <expr>` 抛出异常

## `try` / `catch`

```js
async fn fetchUser(id: string) {
  try {
    let response = await fetch("/api/users/" + id)
    return await response.json()
  } catch (e) {
    print("Error: " + e.message)
    return null
  }
}
```

## 异步闭包

```js
async fn main() {
  let work = async fn() { 21 * 2 }
  print(await work())   // 42
}
```

异步闭包写作 `async fn()`，调用返回 Promise，可用 `await`。

## 异步函数中的状态限制

异步函数**不能**使用 `@State`、`@Store`、`@Effect`、`@Environment`。异步操作应通过**直接调用 Store API**：

```js
// 正确：直接调用 useAppStore()
pub async fn fetchUser(id: string) {
  let store = useAppStore()
  store.actions.setLoading(true)
  let data = await fetch("/api/users/" + id).json()
  store.actions.setUser(data)
}

// 错误：在异步函数里使用 @Store 装饰器
pub async fn fetchUser(id: string) {
  @Store let { setUser } = useAppStore()  // 错误
}
```
